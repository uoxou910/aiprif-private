# サイトB — フレカ置き場2

サイトAと共通のデザインを使用したサイトB。保存先は既存のサイトB専用GASで、サイトA・Dとは分離されています。

- 管理: https://uoxou910.github.io/aiprif-private/edit.html
- 旧公開（GAS変更まで利用可能）: https://uoxou910.github.io/aiprif-private/legacy-index.html
- 旧管理: https://uoxou910.github.io/aiprif-private/legacy-edit.html

## 変更内容
- 公開画面：サイトAと同じ検索・フレカ表示・画像拡大・ページ送り・ヘッダー
- スマホ下部のキャラ切替バーとPC上部のキャラ切替タブを廃止
- 検索対象は「キャラ名＋コーデ名」（ひらがな／カタカナを正規化）
- 管理画面：フレカ管理のみ。所持コーデ・印刷予定はなし
- キャラ名は自由入力。既存の管理GASによるアップロード・編集・削除・公開切替を維持
- 管理者ログイン用パスワードは従来どおりGASで検証

## 公開画面とGASの認証
提供されたサイトBの `Code.gs` では、`GET action=list` は管理者パスワードを求めず、公開フレカのみを返します。管理操作（`POST auth`、`adminList`、`upload`、`update`、`visibility`、`delete`）には `checkPassword_` が適用されます。認証や既存のGAS側コードは変更していません。

## ZIP一括追加
管理画面の「＋ フレカを追加」から画像ファイルまたはZIPを選択・ドロップできます。ZIP内の画像ファイル（サブフォルダも含む）をブラウザ上で展開し、Dと同じプレビュー一覧に追加します。すべての画像についてキャラ名（自由入力）とコーデ名を入力してから、「N件を追加する」で一括登録します。画像以外のファイルやMacのメタデータは除外します。

画像1件の上限は8MB、ZIPは150MB、展開後合計は180MBです。ZIP展開時のみ `fflate@0.8.2` をjsDelivrから読み込みます。通信できない場合はZIPの展開ができません（通常画像の選択は引き続き可能です）。

既存GASにはZIPを直接送らず、展開後の画像を従来の `upload` → `update` APIで1件ずつ登録します。失敗した画像は成功件数とともに画面に表示します。

## データの扱い
既存フレカやGoogle Drive画像、GAS、スプレッドシートは変更していません。リポジトリ側の画面コードのみを変更しています。

## ダーク化・ミクコフラグ

- 管理画面の追加プレビュー各行右側と、編集画面右上に「ダーク化」「ミクコ」の独立したチェックボックスを追加
- 管理画面の検索欄右側の「ダーク化」「ミクコ」を使って絞り込み。文字検索ともAND条件で併用可能（両方チェック時は両方の設定があるフレカのみ表示）
- 既存のサイトB GAS には専用カラム／APIがないため、コーデ名の末尾に互いに区別できる不可視識別子を保存。ダーク化は U+2063を3つ、ミクコは U+2064を3つ。公開・管理画面では自動的に除去して表示するため通常のコーデ名は変わらず、ブラウザのローカル保存ではないため別端末や再読込でも判別できます
- 既存のダーク化フラグだけを持つフレカとの互換性を維持しています
- 旧管理画面や外部ツールでコーデ名を再保存すると、不可視識別子が失われてフラグが解除されることがあります。将来GAS側に専用項目を追加する際はデータ移行を行ってください
